Principles

01Canvas first

Full-bleed canvas; chrome never exceeds the 48px top bar. Panels float with 12px margins and can all dismiss.

02One primary action

Each screen names its job: draw the room, fit out the kitchen, run the service. Everything else is secondary or contextual.

03Summoned, not shown

Library opens on intent, inspector appears on selection, tuning lives in drawers, power features in ⌘K. Max two visible panels.

04Quiet by default

No permanent warning badges. One Review pill aggregates health; issues light up contextually on hover and selection.

05Numbers are the product

Every dimension, count and metric renders in monospace tabular figures. The app reads as a precision instrument.

06Motion explains structure

150–250ms, transform/opacity only. Panels slide from where they belong. Nothing decorative; reduced-motion respected.
